# Phase 2: `compareexpressions.criteria`, and retiring `evaluation_result`

Depends on `slr_parsing` and `lf_toolkit`. The source is currently `parsing.py` (93 lines) and `graph.py` (374 lines).

## Target modules

| Module | Contents |
|---|---|
| `grammar.py` | Token rules and productions as immutable tuples, generated readably **while keeping production order exactly**, because order sets precedence. Also `build_criteria_parser(reserved_expressions)`. |
| `nodes.py` | Module-level dataclasses `EvaluationNode`, `CriterionNode`, `OutputNode`, and a frozen `Edge` |
| `graph.py` | `CriteriaGraph`: `add_evaluation/criterion/output`, `attach`, `add_sufficiencies`, `starting_evaluations`, `generate_feedback` |
| `tree.py` | `CriteriaTree`, `build_tree`, `trees` |
| `render.py` | `to_json()` / `to_mermaid()` for graph and tree, style constants |
| `feedback.py` | `resolve_feedback(graph, tags, custom_feedback=None) -> list[tuple[str, str]]`, `add_feedback_from_tags(result: lf_toolkit.evaluation.Result, tags, graph, custom_feedback=None)`, `criteria_test_data(graphs) -> dict` |
| `errors.py` | `CriteriaError` → `CriteriaGraphError`, `CriteriaEvaluationError` |

## Checklist

### Bugs (regression test first, one commit each)

- [ ] `Tree.mermaid()` sets `stack = self.outgoing` and pops from it, which **empties the tree it renders** (1 child → 0).
- [ ] `generate_criteria_parser()` does `+=` on the module-level default `base_token_list`, so the list grows on every call (16 → 18 after two calls).
- [ ] `build_tree("unknown")` raises `AttributeError` because its error message reads `node.label` on `None`.
- [ ] `add_node(Evaluation(...))` reads the nonexistent `node.sufficiencies`, so it always raises. It also drops `evaluate`.
- [ ] `Node.__eq__` has no `__hash__` (nodes are unhashable) and crashes when compared with a non-Node.
- [ ] `generate_feedback` prints graph internals on an exception. Raise `CriteriaEvaluationError` with the evaluation label instead.

### Restructure (no behaviour change)

- [ ] Split `graph.py` into `nodes.py` / `graph.py` / `tree.py` / `render.py`; nested classes become module-level.
- [ ] `parsing.py` → `grammar.py`. The `OTHER/RESERVED` production combinations are generated by a helper, with the production order checked in a test.
- [ ] Remove the `if __name__ == "__main__"` demo; its criteria strings become parametrised parser tests.
- [ ] Remove the unused `END` constant and the unused `return_node` parameter.
- [ ] Bare `Exception` → `CriteriaGraphError` / `CriteriaEvaluationError`.

### Retire `evaluation_result`

- [ ] Add `feedback.py` with `resolve_feedback`, `add_feedback_from_tags` (skips tags already in `result.tags`, as today) and `criteria_test_data`. `resolve_feedback` skips generators that return `None`.
- [ ] Port the behaviours that still matter from `evaluation_result/tests` (tag de-duplication, custom-feedback override) as `criteria.feedback` tests.
- [ ] Delete the `evaluation_result/` package.
- [ ] Migration notes: `EvaluationResult` → `lf_toolkit.evaluation.Result`; `add_feedback((tag, fb))` → `add_feedback(tag, fb)`; `serialise()` → `to_dict()`. Joining a `simplified` list and attaching `criteria_test_data` become the consumer's job. `to_dict()` emits `tags` only with `include_test_data=True`.

### API (break freely, recorded in `CHANGELOG.md`)

- [ ] `generate_criteria_parser` → `build_criteria_parser`
- [ ] `CriteriaGraph.Evaluation/Criterion/Output/Edge/Tree` → `EvaluationNode`, `CriterionNode`, `OutputNode`, `Edge`, `CriteriaTree`
- [ ] `graph.json()` / `graph.mermaid()` → `to_json()` / `to_mermaid()`

### Types & lint

- [ ] Typed callables: `evaluate: Callable[[Any], dict[str, Any]]`, `feedback_string_generator: Callable[[Mapping[str, Any]], str | None]`.
- [ ] `mypy --strict` clean; `ruff` clean.
